# Codex Easy Launcher — 구현 마일스톤

작성일: 2026-06-23
대상 기획서: `codex-easy-launcher-product-plan.md`

## 0. 타당성 결론 (요약)

**가능.** 기획서의 핵심 전제가 실제 Codex CLI 기능과 맞아떨어진다.

- 채팅 UI ← `codex exec --json` 비대화형 스트리밍 (TUI 스크래핑 불필요)
- 비번 저장 없는 로그인 ← `codex login` 브라우저 OAuth + `~/.codex/auth.json` 감지
- 안전모드 ← Codex 네이티브 sandbox(`read-only`/`workspace-write`) + 승인정책
- 포터블 배포 ← 기존 pastemotion Electron 패키징/CI 자산 재활용

**핵심 기술 결정**: 통합 인터페이스는 대화형 TUI가 아니라 **`codex exec --json`** 으로 간다. 멀티턴은 세션 resume으로 문맥 유지.

**최대 리스크**: 코어 래퍼가 아니라 **윈도우 설치도우미**(node/npm/codex 자동설치 — 백신/PATH/회사PC 권한). 여기에 버퍼를 크게.

## 1. 마일스톤 개요

| MS | 이름 | 목적 | 게이트(통과조건) |
|----|------|------|------------------|
| M0 | 수요검증 | 만들기 전 시장 확인 | 댓글 20+ / 테스터 5+ |
| M1 | 코어 래퍼 PoC | 최대 기술리스크 선제거 | 폴더 골라 exec→채팅 응답 |
| M2 | 로그인·세션 | 무섭지 않은 시작 | 미로그인 감지→OAuth→멀티턴 |
| M3 | 첫실행 설치도우미 | 진입장벽 0 | 깡통 PC에서 한번에 준비 |
| M4 | 안전모드 | 신뢰 확보 | 계획먼저/백업/되돌리기 |
| M5 | 프리셋 버튼 | 빈 채팅 공포 제거 | 6버튼 동작 |

## M0 — 수요검증 (코딩 전, 병행 가능)
- 투두TV 영상/커뮤니티에 기획서 16번 떡밥 게시 ("터미널 때문에 Codex 못 쓰셨나요?")
- 신청 폼/댓글로 테스터 모집
- **산출물**: 테스터 명단, 자주 나온 불만 5개(=프리셋 버튼 후보)
- **게이트**: 댓글 20+ / 테스트 희망 5+ → 통과 시 M1 착수

## M1 — 코어 래퍼 PoC (★최우선)
> "폴더 고르고 한 마디 치면 채팅으로 답이 온다"를 먼저 증명.
- Electron + React 셸 (pastemotion 베이스 포크)
- 폴더 선택 UI → 선택 경로를 작업 디렉터리로
- `codex exec --json "<프롬프트>"` 를 child process로 실행, stdout(JSON)/stderr(진행) 파싱 → 채팅 버블 렌더
- 스트리밍 표시(생각중/도구사용/최종답 구분)
- **산출물**: 로컬에서 도는 채팅창 1개
- **수용기준**: 임의 폴더 선택 → "이 폴더 설명해줘" → Codex 응답이 채팅으로 표시
- **리스크**: codex 미설치 시 그냥 실패해도 OK(이 단계는 설치 가정). JSON 스키마 변동 대비 파서 방어적으로.

## M2 — 로그인 상태 + 멀티턴 세션
- 시작 시 점검: `codex --version`(설치) / `~/.codex/auth.json`(로그인)
- 미로그인 → "OpenAI 공식 로그인" 버튼 → `codex login`(브라우저 OAuth) 트리거 → auth.json 생성 폴링 감지 → 상태칩 ✅
- **멀티턴**: 세션 resume으로 대화 문맥 유지(매 턴 새 exec여도 같은 세션 이어가기). 새 작업=새 세션.
- 비번은 앱에 절대 입력/저장 안 함(문구 노출)
- **수용기준**: 로그아웃 상태에서 버튼 한 번으로 로그인 완료→채팅 가능, 이전 대화 문맥 유지됨

## M3 — 첫실행 설치도우미 (★최대 UX 리스크)
- 마법사: 인터넷 → Node/npm → Codex CLI → 로그인 → 폴더 → 테스트실행
- 상태표시 ✅/❌ + [한 번에 준비하기]
- 설치 순서: winget(Node LTS) → 실패 시 공식 설치파일 안내 → 권한문제 시 수동가이드+진단파일
- **한국어 에러 번역 레이어**: `EACCES`/`ENOENT`/PATH오류 → 사람말 + [다시시도][수동안내][진단파일]
- 기술용어 마스킹: npm→"AI 실행 준비 프로그램", codex→"AI 실행 엔진"
- **수용기준**: Node/codex 없는 깨끗한 윈도우에서 마법사만으로 채팅까지 도달
- **리스크 완화**: 회사/학교 PC(권한제한)·백신 차단 케이스를 처음부터 테스트 매트릭스에. v1은 Codex 번들 금지, "공식 설치 실행"임을 명시.

## M4 — 안전모드 & 신뢰
- 기본값 = **read-only(계획만)**: Codex sandbox read-only로 실행 → 수정 없이 계획/설명만
- 수정 작업은 명시 승인 후 `workspace-write` + 승인정책
- 수정 전 **diff 미리보기**, 자동 **백업**(data/backups/), **되돌리기**
- 위험 작업 경고 / 권한 요청 쉬운 설명
- **수용기준**: 기본 상태에서 AI가 파일을 못 고침. 승인해야만 수정, 수정 후 되돌리기 동작
- **세일즈 포인트**: "AI가 내 파일 맘대로 안 건드림" = 비개발자 신뢰의 핵심

## M5 — 프리셋 버튼 (v0.2)
- 6버튼: 폴더설명 / 문서요약 / 파일정리안 / 오류설명 / README생성 / 계획만보기
- 각 버튼 = 내부적으로 안전 프롬프트 자동생성(기존 파일 수정금지 문구 포함)
- M0에서 모은 실제 불만으로 버튼 교체/추가
- **수용기준**: 빈 채팅에서도 버튼만 눌러 결과 도달

## M6 — 포터블 배포 + 업데이트 골격
- electron-builder portable(ZIP) 타깃 (pastemotion CI 재활용)
- 폴더구조: `data/`(settings/logs/backups/sessions) `skills/`(free·pro) `templates/`
- 관리자권한 없이 실행, 삭제=폴더삭제로 끝
- updater 골격(서명/버전체크) — 실제 자동업데이트는 v4
- **수용기준**: ZIP 풀고 exe 더블클릭으로 M1~M5 전부 동작

## M7 — 베타 + 유료화 골격
- M0 테스터 5명에게 배포 → 화면녹화 데모 → 피드백 루프
- 무료/Pro 분기 골격: 무료(실행·로그인·기본채팅·기본스킬3) / Pro(업무 스킬팩·자동업데이트·고급안전)
- **설치도우미는 절대 유료화 금지**(진입장벽 낮추는 기능은 무료) — 과금은 스킬팩/템플릿/업데이트
- **수용기준**: 테스터가 혼자 설치~사용 완주, Pro 토글 자리만 잡힘

## 2. 추천 진행 순서 & 일정 감

```
M0 (병행, 코딩과 무관)
└ M1 코어래퍼  ──▶ M2 로그인·세션 ──▶ M4 안전모드 ──▶ M5 프리셋
                 └ M3 설치도우미(병렬, 버퍼 크게) ──────────────▶ M6 배포 ──▶ M7 베타
```

- 1차 목표(내부 데모 가능): **M1+M2** — "내 PC에선 채팅으로 Codex가 됨"
- 외부 테스터 배포 가능선: **M3+M6** 완료 시점
- 가장 시간 안 잡히는 곳: **M3 설치도우미**(환경 다양성) → 여유 크게

## 3. 기술 스택 확정
- Electron + React (pastemotion 베이스 재활용)
- child process로 `codex exec --json` 호출 (node-pty는 대화형 필요할 때만)
- 로컬 상태: `data/settings.json`, `install-status.json`, `sessions/`
- 패키징/CI: pastemotion electron-builder 파이프라인 포크
- 비번 미저장. Codex/Node v1 미번들(공식 설치 실행 안내)

## 4. 검증해둘 것 (M1 착수 전 30분 스파이크)
1. `codex exec --json "hi"` 출력 포맷 실측 → 파서 설계
2. 세션 resume 명령/플래그 실측 → 멀티턴 방식 확정
3. read-only sandbox 플래그 실측 → "계획만" 매핑 확정
4. `codex login` 트리거 후 auth.json 생성 경로/타이밍 실측

> 이 4개만 손으로 먼저 돌려보면 M1~M4 설계가 전부 확정됨.
